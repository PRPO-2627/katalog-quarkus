# Katalog – Quarkus

Minimalen večmodulni projekt Maven, ki prikazuje REST API, izdelan z ogrodjem
Quarkus. Korenski projekt je pripravljen za dodatne module; trenutno vsebuje
modul `katalog-rest`.

## Zahteve

- Java 25 ali novejša
- Maven 3.9 ali novejši

## Gradnja

```shell
mvn clean package
```
